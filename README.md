# AVAS 低速提示音设计与合规仿真台

电动车低速提示音（Acoustic Vehicle Alerting System）的浏览器端设计工具：
用实时合成替代供应商录音 + 消声室往返，改一个曲线点半秒内听到结果并完成法规频段检查。

## 启动

直接双击 `index.html`（无需联网、无外部依赖），或：

```powershell
python -m http.server 8000   # 然后浏览器打开 http://localhost:8000
```

建议使用 Chrome / Edge 最新版（需要 Web Audio API 与 AnalyserNode）。

## 文件结构

| 文件 | 职责 |
|---|---|
| `dsp.js` | 纯算法层：FFT、1/3 倍频程能量分配、A 计权、曲线单调三次插值、谐波谱模型、多普勒几何。无浏览器依赖，可在 Node 测试 |
| `app.js` | Web Audio 实时合成引擎、离线合规扫描、驶过引擎、全部 UI 交互 |
| `index.html` | 单页界面与样式 |
| `tests/dsp.test.js` | DSP 单元测试（40 项） |
| `tests/scan.e2e.js` | 合规扫描管线端到端测试 |

```bash
node tests/dsp.test.js
node tests/scan.e2e.js
```

## 工作流

### 1. 设计三条曲线（前进 / 倒车各一套）

- **音高 f₀**：基频随车速 0–30 km/h 连续变化；倒车默认恒频 260 Hz。
- **响度**：参考距离处的目标声压级（dB SPL）。
- **音色（亮度 0–1）**：控制谐波能量向高频分布的程度。
- 点击空白加控制点，拖动修改，双击删除（端点保留）；插值可选**单调三次**（Fritsch–Carlson，保证连续且不过冲）或线性。
- 起步按「起步渐入」斜坡（默认 150 ms）淡入，停止 120 ms 淡出，档位切换 60 ms 交叉淡变，均无咔哒声。

### 2. 合规检查（自动）

每次改曲线后 450 ms 防抖自动重扫，也可点「立即扫描」。对每个车速点：

1. 离线确定性渲染 0.5 s、48 kHz 信号（与实时试听同一合成模型）；
2. 8192 点 Hann 窗 FFT，按 IEC 1/3 倍频程边界对 bin 能量做分数分配；
3. 按目标 SPL 归一化后逐频段与下限比较；
4. 判定规则：**至少 2 个法规频段 ≥ 下限，且线性总级 ≤ 总级上限曲线**。

不合格点在响度图上以红叉标出，汇总表逐点列出缺口最大的频段和差值（dB）。
频段下限表可直接编辑（留空表示该频段无要求），总级上限也是可编辑曲线。

> ⚠️ 默认下限数值参考 UN ECE R138 / GB 7258 体系整理，仅供工程预研；
> 正式认证请以现行法规原文为准并在消声室标定。判定基于目标 SPL 归一化，与声学校准滑块无关。

### 3. 实时试听

「试听」后拖动车速滑块，音高/音色/响度沿曲线连续变化。右栏显示实时分析器测得的
线性总级与 A 计权总级，并对当前车速给出合格/不合格徽标。

- **声学校准**：数字满刻度（0 dBFS）对应的 dB SPL，只影响试听音量与表显。
  消声室实测一个点后，把表显调到实测值即完成校准。
- **参考距离**：响度曲线上 SPL 数值对应的测量距离（默认 1 m）。

### 4. 驶过模拟（多普勒 + 距离衰减）

车辆从侧前方 20 m 驶来、经过、驶离：

- 几何：匀速直线、侧向距离可调（默认 7.5 m，法规常用测量布置）；
- 多普勒：由观察者时刻牛顿迭代反解发射时刻，频移比 `f′/f = 1/(1+Ṙ/c)`，
  通过延迟线的延迟斜率物理实现（非简单变调）；
- 距离衰减：球面扩散 `20·log₁₀(R/R₀)`；
- 顶视图实时显示车辆、麦克风、连线距离、多普勒比与瞬时 SPL。

### 5. 数据交换

- **导出工程 JSON**：曲线、频段下限、合成器参数完整存档，可重新导入；
- **导出曲线 CSV**：前进/倒车两套曲线按扫描步长插值的平铺表，可直接交给工程师或导入 Excel；
- 所有编辑自动保存在浏览器 localStorage，刷新不丢失。

## 合成模型说明

加性合成：`s(t) = Σₕ wₕ(亮度, 模板) · sin(2π·h·f₀·(1+颤音)·t)`，谐波权重平方和归一化为 1，
因此母线增益数值上等于信号 RMS，目标 SPL 与数字电平换算严格可计算。四种谐波模板：
柔和（指数衰减）、饱满（1/h 系列）、引擎感（奇谐波加权）、纯净（近正弦）。
